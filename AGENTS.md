# window-mover

Windows tray app that positions windows by rules. Features and installation are in [README.md](README.md).

- `dotnet build WindowMover.slnx --no-incremental`; incremental builds can wrongly report no warnings.
  There are no tests. Warnings are errors.
- The version is in `Directory.Build.props`. `CHANGELOG.md` is generated by git-cliff on release from the
  conventional commit messages, so do not edit it by hand.
- CI runs on `windows-latest` and packs with Velopack. Keep the `vpk` tool (`.config/dotnet-tools.json`) and
  the `Velopack` package on the same version.
- The in-app updater reads this repository's GitHub releases, so the repository must stay public for
  other people to update.
